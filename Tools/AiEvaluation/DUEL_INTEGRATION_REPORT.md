## 체인과 듀얼 화면

- Auto는 체인 대응과 소환·공격 등 주요 타이밍에서 확인합니다. On은 엔진이 제공하는 발동 후보를 전부 표시합니다. Off는 임의의 프리 체인을 넘기고 강제·유발 효과 선택을 유지합니다.
- 패, 필드, 묘지, 제외 존에서 발동할 수 있는 카드나 해당 카드 더미에 금색 펄스를 표시합니다. 카드를 누르면 가능한 발동·세트·소환을 보여줍니다. 선택 응답이 잠시 보류되면 해당 확인 창과 효과를 유지합니다.
- 동시에 발동한 효과는 일러스트로 순서를 고를 수 있습니다. 실제 티아라멘츠 묘지 효과에서 선택 순서와 역순 해결, 후속 발동 확인을 검증했습니다.
- LP와 아바타는 슬래시 형태 HUD에 배치했습니다. LP 감소는 붉은색, 회복은 초록색으로 표시합니다. 메탈릭 필드, 엑스트라 몬스터 존과 링크 표시, 금색 페이즈 탭, 체인 번호 엠블럼과 효과음이 함께 적용됩니다.
- 양쪽 가로 노치 위치를 모사해 44pt에 해당하는 조작 영역, 카드 상세, 페이즈, 묘지·엑스트라·제외 탭, 12장 손패의 스크롤과 조이스틱 포커스를 확인했습니다. 아이폰 UI 검증 범위는 헤드리스 레이아웃과 입력 테스트입니다.

## AI 전술

- 실제 엔진에서 갑부 고블린은 통과시키고 우라라를 원죄보에 사용했습니다. 포영과 뵐러는 전투로 묘지에 가야 효과가 나오는 토마토·터틀을 보류하고, 실제 필드 효과를 발동한 에어맨에 대응했습니다.
- 메이루의 묘지 융합을 체인 1, 설릭의 서치를 체인 2에 두었습니다. 엔진에서 우라라가 설릭을 무효화한 뒤 메이루가 키토칼로스를 소환했습니다.
- 후공에 별도의 전개 카드가 있으면, 무효화가 남은 바로네스 앞에서 증원을 먼저 사용합니다. 바로네스가 증원을 막은 뒤 무효화 사용 상태가 반영되고 에어맨 후속 전개가 남는 것을 확인했습니다.
- 일반 소환과 여러 몬스터의 동시 특수 소환을 세어 니비루의 다섯 번째 소환 타이밍에 대비합니다. 전개용 중간 몬스터만 남은 경우에는 이어갈 수 있습니다. 실제로 공개된 번개 앞에서는 추가 소환 카드를 손에 남겼습니다. 즉시 사용할 수 있는 무효화가 서면 보호를 받는 전개를 허용합니다.
